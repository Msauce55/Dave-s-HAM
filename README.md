# Dave-s-HAM
# 📡 Dave's Ham Radio Portal

**A modern multi-page Streamlit dashboard for Amateur Radio operators, students, and clubs.**

Built with a deep space + radio theme, real-time space weather data, practical tools, and community features.

---

## 🌟 Features

| Page | Description |
|------|-------------|
| **Home** | Live Solar Flux, K-Index, A-Index, and Sunspot Number from NOAA |
| **Space Weather** | Real-time geomagnetic data, K-index chart, and band condition guidance |
| **DX / POTA / APRS** | Sample DX cluster spots, Parks on the Air activators, and APRS map |
| **Repeaters** | Searchable local repeater directory + digital modes reference |
| **Callsign & License** | Live US callsign lookup (callook.info), practice exam questions, and band plan |
| **Emergency & Club** | Net schedules, club calendar, and ARES/RACES quick reference |
| **Calculators** | Dipole, Yagi estimate, coax loss, and wavelength calculators |
| **Dave's Blog** | Community blog where anyone can post |
